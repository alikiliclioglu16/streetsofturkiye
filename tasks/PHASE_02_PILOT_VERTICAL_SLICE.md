# Phase 02 — Pilot Vertical Slice

## Goal

Transform the graybox engine into the final target quality for İstanbul, Nevşehir and Gaziantep.

## Required features

- import optimized Meshy GLBs through the asset registry;
- keep placeholders for missing assets;
- complete three interaction types;
- integrate both guides;
- add environment, guide, UI and success audio channels;
- add collection screen;
- implement low/medium/high quality profiles;
- add city intro camera sequence and skip;
- add region progress display;
- verify touch usability and performance.

## City interaction minimum

### İstanbul

- inspect İznik tile and find a motif;
- inspect Galata silhouette or viewpoint detail;
- observe Bosphorus geography;

### Nevşehir

- identify erosion-formed fairy chimney details;
- assemble or decorate a clay pot;
- inspect an underground rolling stone door;

### Gaziantep

- find a detail in the Zeugma mosaic panel;
- select baklava ingredients in order;
- repeat a coppersmith rhythm.
