# Streets of Türkiye — Handover

**Date:** 30 July 2026 · **For:** picking this project up in a fresh conversation

Read this, then `docs/DECISION_LOG.md`. The decision log is 117 entries and is
the real memory of the project — every one of them records something that was
got wrong first. This document is the map to it.

---

## 1. What this is

A 3D educational web game about Türkiye's 81 provinces, for American children
aged roughly six to ten. A child picks a province on a map, walks a street with
a guide, collects something at each stop, answers a short quiz, and earns a star.

**Owner:** Ali Kılıçlıoğlu, Houston Education Attaché Office
**Repo:** github.com/alikiliclioglu16/streetsofturkiye (public)
**Live:** streetsofturkiye-xi.vercel.app (Vercel, root directory `app`)

Stack: Next.js 16, React 19, TypeScript strict, Three.js 0.185, React Three
Fiber 9, Drei 10, Zustand 5, Zod 4, Vitest 4.

**The content is English only.** The target audience is American schoolchildren.
`DEFAULT_LOCALE = 'en'`, no language toggle.

`npm run gate` is green: 81 cities, 249 stops, 84 questions, **320 tests**,
clean lint and typecheck, 4 routes built.

Assets total 70.63 MB on disk; a single city visit downloads far less because
only the resident guide and that city's art are fetched.

**The pilot is still three cities.** `PILOT_CITY_IDS` is what phase 02 is judged
against and is deliberately narrower than `PLAYABLE_CITY_IDS`. Several tests are
scoped to it, because a city opened before its art legitimately has unresolved
asset ids and no music, and a rule that forbids those would forbid opening a
city at all.

**Immediately outstanding:**

- **No child has ever played this**, and **mobile has never been measured**
- `scaleToBrief` is not wired up, and sixteen delivered assets are drawn at a
  size the layout does not assume (D-120). Nothing is broken by it today; it
  wants a deliberate change and a screenshot round.
- The three new Gaziantep stops have not been seen by anyone. Their identity
  rests on their file names and on a metallic-channel reading that agrees with
  the brief — which is more than nothing and less than a look.

The first of those is the largest unknown in the project and has been for weeks.

## 3. How to work on it

```bash
cd app
npm run gate     # sync + validate + lint + typecheck + test + build
npm run content:scenes    # regenerate content/scenes/*.json after editing the generator
npm run content:check     # canonical validation only
```

`npm run gate` must be green before packaging. Nothing ships that fails it.

**The package must include `legacy/index.html`.** It sits at the repo root, so
the recipe below missed it, and `validate-canonical.mjs` checks the canonical
authority by hashing that file. Working from the package alone, the gate
therefore fails on its first step for a reason that has nothing to do with the
code — and a real regression would be indistinguishable from it. It is 1.4 MB
and it is the SHA the whole content layer is anchored to.

**Packaging for the owner** — they upload via GitHub Desktop, never the web UI
(the web upload has dropped files and scrambled folders):

```bash
# copy app/{src,tests,scripts,public/assets,configs} + content + docs
#      + asset-manifests + legacy/index.html + CLAUDE.md
zip -qr TAM-PAKET.zip app content docs asset-manifests legacy CLAUDE.md \
  -x 'app/node_modules/*' 'app/.next/*'
```

Then `present_files` it. The owner extracts over the repo folder, overwrites, and
pushes with GitHub Desktop.

## 4. The shape of the code

```

                            source prototype under a recorded SHA. Never edit by
                            hand; the validator compares 1,413 strings to a
                            baseline and will fail.
content/scenes/*.json       Generated by scripts/build-scenes.mjs. Technical
                            layout only — never canonical prose.
app/scripts/
  build-scenes.mjs          The layout engine. Stop positions, route, dressing,
                            horizon, animals, balloons, trees. Most level design
                            lives here.
  build-ground-texture.mjs  Generates cobblestone and red sand procedurally.
  measure-model.mjs         Reports everything the registry needs about a GLB.
                            Run it on every delivery before deciding anything.
  simplify-model.mjs        Reduces over-budget geometry (meshoptimizer + sharp).
  optimize-textures.mjs     Sizes textures by role, for deliveries whose mesh is
                            already in budget and whose cost is in the maps.
  set-model-scale.mjs       Re-authors a delivery to an agreed height, on y = 0.
  validate-canonical.mjs    Reachability, ring overlap, text leakage, sync.
app/src/engine/             Pure logic: assets, heroes, npc, audio, controls,
                            camera, progress, interactions, environment, scene.
app/src/components/three/   Renderers. Thin; the thinking is in engine/.
app/tests/                  318 tests. playthrough.test.ts simulates a whole
                            visit per city using the running game's own functions.
```

## 5. Rules that were learned the hard way

These are not style preferences. Each one cost real time.

### Assets

**Measure every delivery before integrating it.** Bytes, triangles, meshes,
materials, `alphaMode`, `doubleSided`, world bounding box, base offset relative
to y = 0, animation clip names. Record all of it in the registry with the file's
SHA-256; a test asserts the registry matches disk. Delivery notes have been wrong
more than once.

**Measurement narrows an asset down; it does not identify it.** A file named
`Beyoğlu` measured like a row of building facades and was placed twice as
scenery. It was a ferry. Anything whose identity rests on its filename gets
asked about (D-078). A grove briefed as pistachio arrived as olives and is
registered as `kit_olive_grove` (D-117).

**Textures by role, never all at maximum.** Base colour 2048 (1024 for small
objects), normal and roughness one step below. Six deliveries in a row arrived
with four 4096 px maps; one was 70 MB and came down to 2.94 MB with no visible
loss (D-057). Use `optimize-textures.mjs` when the geometry is already in
budget — `simplify-model.mjs` takes every map to 1024, which the mosaic panel
cannot have.

**Meshy bakes a black emissive map into every export** and sets `emissiveFactor`
to [1,1,1] beside it, so a 4096 px texture is loaded to add nothing at all.
Measure before dropping it; the next delivery may have a lantern in it (D-118).

**Never force `doubleSided` off.** Right for a closed shape, destroys a thin one:
a flag is one plane and culling its back face draws half of it. Two flags, a
market awning and nearly a carpet were lost to this (D-089). `alphaMode: OPAQUE`
is safe to force.

**Lock UV seams when simplifying.** Without `lockBorder`, the simplifier welds
across them and the texture tears — the first Galata Tower came back white and
shapeless (D-054b).

**Skinned models must be cloned with `SkeletonUtils.clone`.** `Object3D.clone`
keeps the original bones and the copy renders at bind pose or the wrong scale
entirely. This is what rendered Nasreddin Hodja 1.7 cm tall (D-042).

**Meshy exports arrive at inconsistent scale.** Several have had a 0.01 armature
and render at centimetres; more often they arrive normalised into a bounding box
and come back at exactly 2.00 or 4.00 m whatever they depict. `AssetInstance`
measures the mounted model and scales it to the recorded height — **but only
outside a half-to-double band**, which is where most normalised exports land.
`scaleToBrief` reads as though it closes that gap. It does not: nothing in the
engine reads it (D-120). Until that changes, correct a disagreeing delivery in
the file with `set-model-scale.mjs` rather than trusting the registry to do it.

**A stop object is child-scale — one to five metres.** It is something to walk up
to, not scenery. Hagia Sophia was built as a stop and had to be moved to the
horizon; the fairy chimneys had to shrink from six metres to four and a half,
which was also why Nevşehir's street would not compress (D-066, D-110).

### Level design

**Every city answers four directions:** walls to the sides, distance in front,
something to turn round to. The answers are regional and nothing is borrowed
between cities. A test holds that line.

**Ground is scenery; bounds are gameplay.** They were the same rectangle and
things placed outside the play area floated over sky (D-082). Paving runs 44 m
past the boundary.

**Landscape plates are aligned by their near edge, not their centre.** A 78 m
valley centred on the boundary swallowed the spawn (D-101).

**Spacing is asked for, then checked against the trigger rings.** Two stops
closer than their rings would open each other, so geometry has the last word
(D-100).

**Nothing stands where the child walks**, measured against the route polyline
rather than against x = 0 (D-070).

**The route steps round each stop.** One waypoint per stop meant the leg to the
next one ran straight through the object at this one — the markers led a child
into Galata Tower (D-073).

### Motion

**Choose what it should look like from where the child stands, then pick the
motion.** Three attempts at balloons went the other way: six metres of drift was
invisible, a wrapping crossing was invisible for a minute and then teleported
(D-109).

**The application moves things through the world; clips only move limbs.**
Applying a clip's root motion on top makes feet skate. Cat, horse, tram, NPCs all
follow this.

**Anything that moves takes reduced motion as zero strength**, rather than
threading a flag through every component.

### Audio

**Music only.** The synthesised ambience bed was cut after two attempts — filtered
noise reads as water however it is shaped, and the owner heard waves over
Cappadocia both times (D-103). The `ambience` channel and its mute switch remain
for recorded audio.

**Interface cues are synthesised**, so they cost nothing: triangle oscillators on
a pentatonic set. The wrong-answer cue is deliberately not a buzzer.

**The guide's voice is browser `speechSynthesis`.** The owner has heard it and
called it "GPS-like"; they will supply real recordings at the end of the project.
Keep it until then — `speak()` is the whole interface and recordings replace it
without touching the callers.

**Audio unlocks on a gesture.** The intro button normally; the first tap or key
press when a finished city skips the intro.

### Working practice

**Cities are opened before their art is finished.** Nevşehir and Gaziantep both
went live with placeholder stops, and both immediately exposed code that assumed
the shape of the cities it had already seen. Gaziantep's three stops broke the
NPC placer, which required four (D-115).

**The most valuable tests simulate a whole visit** using the running game's own
functions. `playthrough.test.ts` found that the route markers led into a
building (D-073) and that the spawn had drifted inside a mosque.

**I cannot see the screen.** The automated browser tab renders in the background
where animation is throttled to zero frames, so the 3D scene never mounts.
Everything is verified at the data, schema, HTTP and DOM level; visual judgement
comes from the owner's screenshots. Three assets were integrated wrongly because
of this — a ferry as facades, torn flags, black trees — and all three were caught
by a screenshot. **Ask for one after every deploy.**

## 6. Decisions worth knowing before touching anything

The full log is `docs/DECISION_LOG.md`, D-001 to D-117. These are the ones that
will bite:

- **D-012 / D-072** — the hero mesh is never reduced *at runtime*. The authored
  budget was lowered from 180–250k to 70–120k triangles with the owner's
  approval; the renderer still may not touch it.
- **D-014** — English only.
- **D-016** — guided mode is retired and is not coming back.
- **D-023** — stops present and hand over the collectible. They do not ask
  questions; questions live only in the quiz gate.
- **D-031** — the celebration runs on a clock, not on reports that may never
  arrive.
- **D-033** — saved progress is reconciled against current content, never
  trusted. A save from an older shape once made a city report itself finished.
- **D-036 / D-055** — shared `kit_` props stay under 2 MB because their cost is
  paid in all 81 provinces; one-off `city_` landmarks get 4 MB.
- **D-050 / D-051** — landmarks are at storybook scale and each stop's camera
  distance is derived from its object's height.
- **D-094** — a finished city opens on the street, not on its summary.
- **D-113** — the dance is gone. Both guides celebrate with a short gesture
  sequence.
- **D-120** — `scaleToBrief` is documented, set on twenty-five entries, asserted
  in four tests, and read by nothing. Do not rely on it.
- **D-121** — a solid object is one axis-aligned rectangle. A gate, an arch or a
  colonnade cannot be walked through; it needs two footprints and a gap.
- **D-122** — balloons are Nevşehir's only.
- **D-123** — "open" is not "finished". Tests that assert completeness are
  scoped to `PILOT_CITY_IDS`; what holds for every city is that it stays
  walkable on placeholders.

## 7. What to do next

In the order I would do them.

**1. Put it in front of children, and open it on a tablet.** The largest unknown
in the project, and only real use answers it. Everything learned about this from
the owner's side — cats too small, balloons too slow, tram sideways, waves in
Cappadocia — came from someone looking at it. A child looking at it will find
more. `?debug=1` opens the performance overlay on the deployed build (D-017), so
a tablet and a screenshot close half of this today.

**2. Decide what to do about `scaleToBrief` (D-120).** Sixteen delivered assets
are drawn at a size the layout does not assume. Making the flag live is a small
change and a large visual one, so it wants to be taken deliberately, on its own,
with screenshots of all three cities either side of it.

**3. Kars's art.** The city is open and every model in it is a placeholder. The
brief is written: four horizon pieces (church shell, cathedral, walls, gorge) and
three stops (a carved doorway with a rubbing half taken, a platform with the nose
of the Eastern Express at the end of it, a gravyer stall with one wheel cut). Then
a theme.

**4. Then a fifth city.** Everything needed is in place: the shared kit, three
regional grounds, the planting table, the animal table, the layout that handles
three stops as well as five. A new city needs its three-to-five stop objects, a
horizon, a theme, and a line in `PLAYABLE_CITY_IDS`. Adding one now costs a
morning, which it did not before Kars.

**Still unbuilt:** recorded voice and ambience, a collection screen across
cities, and any measurement of how this performs on the devices most of its
audience will use.
